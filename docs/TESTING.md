# Beeline v1 — утренний чек-лист ручной проверки

Сценарии собраны ночью 23→24.08 по твоим реальным файлам. Приложение уже
запущено скрыто; всё вызывается через Ctrl+Opt+Cmd+F. Отмечай прямо здесь
или кидай находки в чат. ⭐ — критичные, остальное по настроению.

Известное заранее, НЕ баги — не трать время на репорт:
- Холодный многословный поиск (вставка целиком) до ~315 мс — ускорение уже
  в работе в твоём воркетри. Печать по буквам быстрая (кэш дозаписи).
- Right в результатах поиска правит запрос, а не делает Reveal — принятое
  толкование §5, записано в #26.
- «Put Back» в Финдере может не предлагаться для затрэшенного из Beeline —
  цена ухода от Finder-скриптинга (#28).
- Примонтированные тома не индексируются поиском — пробел спеки, тикет #33
  (браузинг по пути работать должен).

## 0. Обязательное утреннее (5 минут) ⭐

1. **Физический шорткат.** Нажми Ctrl+Opt+Cmd+F руками (не скриптом) из
   любого приложения, включая фуллскрин. Жду: окно появляется НА текущем
   Space, сфокусировано, ввод активен. Повторное нажатие прячет. Это
   единственная непроверенная часть активации (синтетика не доказательство).
2. **Диалог «T3 Code wants to control Finder»** если висит/всплывёт —
   Don't Allow (это флаковый интеграционный тест корзины, не приложение).
3. **Cmd+W на Табе.** Открой второй Таб (Cmd+T), закрой его Cmd+W. Жду:
   закрылся Таб, окно живо. На единственном Табе Cmd+W = свежий Temporary.
   (Меню Tauri, перехватывавшее Cmd+W, ночью заменено — нужен глаз.)

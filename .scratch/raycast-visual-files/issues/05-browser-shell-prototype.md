# Prototype the browser shell

Type: prototype
Status: resolved
Blocked by: 01

## Question

What is the smallest disposable Raycast prototype that can prove or disprove a coherent browser-like shell with visible Tabs, a focused Path Input for new Tabs, a primary file list, back/forward navigation, keyboard control, and complete mouse reachability? Record observed behavior and constraints; do not turn the prototype into production implementation.

## Answer

Superseded without implementation. Research showed that Raycast cannot express the required Tab strip, input model, and mouse behavior. The product will instead compare three dedicated application hosts under one benchmark in tickets 14 through 17.

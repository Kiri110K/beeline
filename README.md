# Beeline

A personal, shortcut-driven macOS file browser (working name; formerly Visual Files). Tauri v2 + React + TypeScript; Rust owns the filesystem and system integration.

- Specification: `docs/SPEC.md`
- Domain glossary: `CONTEXT.md`
- Decisions: `docs/adr/`

## Develop

```sh
pnpm install
pnpm tauri dev    # run the app
pnpm typecheck
pnpm lint
```
